本模块由两个并列的前端目录组成：
- `demo/`：基于 Tailwind CSS（CDN）+ ECharts 5 + Lucide 图标构建的深色科技风演示入口，`index.html` 作为导航首页以卡片网格形式链接到各子页面（dashboard/equipment/tasks/alerts/campus-map/gantt/personnel/resource-board/efficiency），每个 `.html` 文件自包含完整页面结构；共享样式集中在 `assets/css/theme.css`，共享脚本在 `assets/js/app.js`（通过 IIFE 暴露 `window.App`，提供 toast、modal、select 下拉、导航渲染等通用 UI 组件），Mock 数据位于 `assets/data/extracted_data.json` 与 `assets/js/mock-data.js`，地图逻辑在 `assets/js/campus-map.js`，另有 `scripts/extract_data.py` 用于从外部数据源抽取 JSON。
- `static/`：另一个独立的前端应用入口 `index.html`（约11000行单页应用），采用侧边栏 + 主内容区布局，内置大量 CSS 变量与组件样式（KPI 卡片、Modal、可搜索下拉框等），并通过 `status_dropdown.js` 提供本地状态下拉交互，依赖 ECharts 5.4.3 与 xlsx 进行图表和 Excel 导入导出，附带 PBOM 导入模板与品牌图片资源。
两目录相互独立、无构建工具依赖，均可直接通过浏览器打开 HTML 运行。
