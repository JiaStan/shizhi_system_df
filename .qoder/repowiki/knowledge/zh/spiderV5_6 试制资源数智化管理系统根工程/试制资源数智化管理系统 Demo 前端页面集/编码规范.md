- 每个功能模块以独立 HTML 文件组织（如 dashboard.html、equipment.html），页面内联 `<style>` 并引用共享 theme.css 与 CDN 资源，保持单文件可独立运行。
- 全局通用 UI 能力（toast、modal、select 下拉、导航渲染）统一封装为 `window.App` IIFE，各页面通过调用该 API 复用，避免重复实现。
- Mock 数据集中存放于 `assets/data/` 与 `assets/js/mock-data.js`，页面加载后直接消费这些 JS 对象而非发起网络请求。
- 颜色与主题通过 CSS 自定义属性（`--brand-primary`、`--success`、`--danger` 等）定义，UI 组件仅引用变量而不硬编码色值。
- 图标统一使用 Lucide 的 `data-lucide` 属性配合 `lucide.createIcons()` 初始化，不在 HTML 中手写 SVG。
