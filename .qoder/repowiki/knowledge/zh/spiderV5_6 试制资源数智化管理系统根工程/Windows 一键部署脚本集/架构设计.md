本模块是一组纯批处理（.bat）脚本与 SQL 初始化文件，作为上层 Python/FastAPI 应用在 Windows 环境下的部署入口，不引入额外框架。整体采用「编排器 + 步骤脚本」的扁平结构：`0_一键部署.bat` 与 `run_all.bat` 作为顶层编排入口，顺序调用 `1_install_mysql.bat` → `2_config.bat` → `3_install_python_deps.bat` → `4_init_database.bat` → `5_start_server.bat`；同时提供 `step1~step5` 同名脚本供独立执行。数据库初始化由 `sql/create_database.sql` 完成（创建 `warehouse_data` 库、utf8mb4 字符集及可选专用用户 `spider_v5`），业务表则委托给外部 `backend\scripts\init_db.py`。每个步骤脚本通过 `where`/`errorlevel` 检查前置条件（如 mysql 命令是否存在、`.env` 是否已生成），失败时输出中文提示并 `exit /b 1` 中断流水线。所有脚本统一以 `chcp 65001` 切换 UTF-8 编码，并通过 `cd /d "%~dp0"` 确保从任意目录均可正确定位相对路径。
