根目录作为多子模块的编排层：`backend/` 以 FastAPI 应用为入口（`main.py`）注册各业务模块路由并暴露 `/api/*` REST 接口；`webui_ref/` 是 NestJS + React/Vite 的全栈参考实现，通过代理将 `/api` 转发至本地 `localhost:8000` 的后端服务；`demo/` 提供无需依赖的纯静态 HTML 原型页面，复用同一套设计体系；`setup/` 与根级脚本（`start_server.py`、`stop_server.bat`、`build_windows_package.sh`、`insert_credentials.py`）负责 Windows 环境下的数据库初始化、凭证占位插入与服务启停。前后端共享约定为 JSON 响应体 `{code, message, data}`、ISO 8601 时间格式以及统一的 `/api/resource/*` 前缀，所有新增模块需参照 `backend/modules/resource` 的结构在 `backend/modules/` 下扩展并在 `backend/main.py` 注册路由。
