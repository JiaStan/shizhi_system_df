- 每个步骤脚本均以 `@echo off` 开头，使用 `setlocal` 隔离环境变量，并在末尾用 `endlocal` 恢复。
- 脚本通过 `cd /d "%~dp0"` 切换到自身所在目录后再 `cd ..` 回到项目根，保证从任意工作目录调用均能正确解析相对路径。
- 对外部命令（如 `mysql`、`python`、`pip`）先使用 `where` 探测存在性，不存在时输出中文错误提示并 `pause` + `exit /b 1` 中止。
- 对关键操作后的返回值使用 `if errorlevel 1` 判断，失败时打印 `[ERROR]` 提示并终止后续步骤。
- 所有脚本首行执行 `chcp 65001 >nul` 将控制台代码页切换为 UTF-8，确保中文输出不乱码。
- SQL 初始化统一使用 `CREATE DATABASE IF NOT EXISTS` 与 `utf8mb4` 字符集，避免重复建库报错并支持中文存储。
