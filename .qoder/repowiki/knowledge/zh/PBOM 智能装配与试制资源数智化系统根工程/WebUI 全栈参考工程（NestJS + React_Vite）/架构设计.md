采用前后端同仓 monorepo 结构：`server/` 为 NestJS 应用，入口 `main.ts` 通过 `@lark-apaas/fullstack-nestjs-core` 的 `configureApp` 初始化并注册 HBS 视图引擎，将构建产物 `dist/client` 作为静态页面渲染；`app.module.ts` 引入平台 `PlatformModule` 和全局异常过滤器，并以 `ViewModule` 作为兜底路由模块放在最后。`client/` 为 Vite + React 前端，使用 `react-router-dom` 在 `app.tsx` 中集中声明页面路由（项目、试制资源等模块），页面按功能拆分为 `pages/*Page` 目录，UI 层由 `components/ui`（Radix-based shadcn 组件）、`components/business-ui`（领域组件如 form、tiptap-editor、entity-combobox、user-select 等）和 `components`（Layout、GlobalSearch 等）三层组成；数据访问通过 `@tanstack/react-query` 在 `business-ui/api` 下按领域组织 service/queries。`shared/` 存放前后端共享的 API 接口与静态 mock 数据。构建流程通过 `vite.config.ts` 的 alias `@` 指向 `client/src`，开发时 Vite 代理 `/api` 到 `localhost:8000`，生产构建后由 NestJS 直接 serve 静态 HTML。
