- 前端页面以 `*Page` 命名文件夹并在 `client/src/pages` 下按业务域（Projects、ResourceDashboard、SystemSettings 等）独立组织，路由集中在 `app.tsx` 中声明。
- 业务组件遵循 `domain-select` / `domain-field` 模式：每个领域（chat、department、user 等）在 `business-ui` 下提供 `*-select`、`*-field`、`types.ts`、`utils.ts` 等文件，并通过 `index.tsx` 统一导出。
- 可组合的复杂组件（如 entity-combobox、form、tiptap-editor）拆分为 base-* 子组件 + hooks + context 的组合式架构，通过 props 与 Context 暴露能力而非内部状态耦合。
- API 调用按领域拆分到 `business-ui/api/<domain>/service.ts` 与 `queries.ts`，使用 TanStack Query 封装查询逻辑，避免在组件内直接调用 axios。
- 后端模块遵循 NestJS 标准三段式（controller/service/module），新增业务模块需在 `app.module.ts` 的 `@route-section: business-modules` 注释区间内注册。
- 前后端共享类型统一放置在 `shared/` 目录下（如 `api.interface.ts`、`plugin-types.ts`），通过 npm workspace 或路径引用保持类型一致。
