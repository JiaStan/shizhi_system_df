根目录作为多子模块编排层：`backend_api` 以 FastAPI `main.py` 为统一入口，按 `/api/{domain}` 前缀挂载项目管理、爬虫调度、PBOM 解析、到货融合、关键件评分、排程与资源等子路由；`webui_ref` 是 NestJS + React/Vite 的全栈参考实现，通过代理将前端 `/api` 请求转发至本地 `localhost:8000` 的后端服务；`demo_pages` 提供无需依赖的纯静态 HTML 原型，复用同一套设计体系；`windows_setup` 与根级脚本（`start_server.py`、`stop_server.bat`、`build_windows_package.sh`、`insert_credentials.py`）负责 Windows 环境下的 MySQL 建库、环境变量配置、Python 虚拟环境安装、数据库初始化及服务进程管理。前后端共享约定为 JSON 响应体 `{code, message, data}`、ISO 8601 时间格式以及统一的 `/api/resource/*` 前缀，新增业务需参照 `backend/modules/resource` 结构在 `backend/modules/` 下扩展并在 `backend/main.py` 注册路由。
