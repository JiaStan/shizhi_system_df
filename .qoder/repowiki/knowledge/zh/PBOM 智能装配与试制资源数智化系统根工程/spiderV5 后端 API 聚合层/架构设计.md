backend/main.py 是唯一进程入口：加载 .env 与 Settings，注册 CORS 中间件与 BusinessError 全局异常处理器，然后通过 app.include_router 将 projects、crawlers、pbom、qr_arrival、delivery、critical_parts、scheduling、system、modules.resource 等子模块的 router 挂载到 /api/projects、/api/crawlers、/api/pbom、/api/delivery、/api/critical、/api/schedule、/api/system、/api/resource 等命名空间；startup/shutdown 钩子负责启动/停止 scheduling.scheduler 与 crawlers.crawler_manager 两个后台任务，并在 __main__ 中通过 signal/atexit 确保优雅退出。各业务子模块仅依赖 core_and_config 提供的 settings、数据库连接与 logger，彼此不直接耦合，跨域协作通过共享 MySQL 表与 Pydantic Schema 契约完成。
