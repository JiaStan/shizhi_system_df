本模块由两个并列且完全独立的前端目录组成，均无需构建工具即可通过浏览器直接打开运行：
- `demo/`：基于 Tailwind CSS（CDN）+ ECharts 5 + Lucide 图标的深色科技风多页应用。`index.html` 作为导航首页以卡片网格链接到 dashboard/equipment/tasks/alerts/campus-map/gantt/personnel/resource-board/efficiency 共9个子页面；每个 `.html` 文件自包含完整页面结构并通过 `<link>` / `<script>` 引入共享资源。共享 UI 能力集中在 `assets/js/app.js`，通过 IIFE 暴露 `window.App` API（toast、modal、select 下拉、确认对话框、导航渲染），各页面调用该 API 复用通用组件；Mock 数据集中存放于 `assets/data/extracted_data.json` 与 `assets/js/mock-data.js`，地图逻辑在 `assets/js/campus-map.js`，主题样式在 `assets/css/theme.css`；另有 `scripts/extract_data.py` 用于从外部数据源抽取 JSON。
- `static/`：另一个独立的单页应用入口 `index.html`（约13700行），采用侧边栏 + 主内容区布局，内置大量 CSS 变量与组件样式（KPI 卡片、Modal、可搜索下拉框等），并通过 `status_dropdown.js` 提供本地状态下拉交互，依赖 ECharts 5.4.3 与 xlsx.js 进行图表和 Excel 导入导出，附带 PBOM 导入模板与品牌图片资源。
两目录相互隔离、无共享代码，各自构成完整的演示入口。
